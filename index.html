Conhecendo o CSS

O que é CSS?

CSS significa Cascading Style Sheets, ou, em português, Folhas de estilo em cascat.

É a linguagem responsável por definir a apresentação visual do documento HTML.

Como trabalhar com o CSS?

Existem três formas clássicas de colocar o CSS em um arquivo HTML:

  • CSS inline
  • CSS interno
  • CSS externo

Conhecendo o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através de um atributo chamado de style
